# 输入文件规范

[首页](../README.md) · [操作指南](usage.zh-CN.md) · [English](inputs.en.md)

输入数据由使用者自行准备。本仓库不附带实验数据或供下载的人工合成输入数据集。

## FASTQ：每个样品一个文件

- 已按样品拆分，标准四行 FASTQ，Phred+33 质量编码；后缀为 `.fq`、`.fastq`、`.fq.gz` 或 `.fastq.gz`。
- FASTQ 的完整路径及所选结果路径不能含空格、Tab 或其他空白字符，因为 Trim Galore 0.6.10 不支持这些路径。脚本会在检查依赖及提交作业前拒绝此类路径。
- 选择一个 read end，通常为 R1，并确保与参考方向匹配。不要把 R1 和 R2 混在一起作为输入。提供原始 reads，流程会去除 Illumina 接头和低质量末端。
- 序列只能含 A/C/G/T/N，长度必须与质量字符串一致。同一样品的 read 标识必须唯一，才能可靠恢复原来的 A。
- 该流程针对无分子 UMI 的文库。i5/i7 是样本 index，不是分子 UMI；流程不执行 UMI 提取或去重。

## 参考：原始扩增子 FASTA

- 提供**未经 A→G 转换**的原始目标 insert，按 RNA 正向书写，使用 DNA 字母（用 T，不用 U）。不要包含测序接头或样本 index。
- 每样品可以有一条或多条记录，每条都要有唯一的 `>record_id` 和含 A 的非空序列。只允许 A/C/G/T/N，小写会转换为大写。允许 N，但可能降低比对率。
- 记录 ID 以字母或数字开头，只能含字母、数字、`_`、`.` 或 `-`。不能含 `_AG_converted`，不能使用保留名 `ALL`、`ELSE`、`Median`、`Mean`、`discard`、`control`，也不能以 `Median_` 开头。
- `>` 后第一个空白分隔字段作为 ID，后面的描述不参与分析。输出坐标是相对于这条参考、从 1 开始的位置。
- 使用未压缩的纯文本 FASTA。不需要基因组、GTF/GFF、现成索引或单碱基注释；流程会自行生成转换参考、Bowtie 索引和注释。
- 如果多个参考经 A→G 转换后相同，就无法可靠区分。流程会给出警告，并按唯一比对设置排除多重比对 reads。

## samples.tsv：三列 Tab 分隔表

仓库内的文件只有表头。按下面的含义填入自己的行，不要改变列顺序：

| 列名 | 填写内容 |
|---|---|
| `sample` | 唯一样品 ID；以字母或数字开头，只含字母、数字、`_`、`.` 或 `-`；不能含 `_AG_converted` |
| `fastq` | 已存在的 FASTQ 路径，例如 `/path/to/your/reads/sample_R1.fq.gz` |
| `reference` | 已存在的原始 FASTA 路径，例如 `/path/to/your/references/amplicons.fa` |

一行代表一个样品，样品名忽略大小写后也不能重复。列间使用真正的 Tab，保存为 UTF-8 文本；允许 UTF-8 BOM。不要添加其他列，也不要像写 shell 命令那样给路径加引号。绝对路径最直观；相对路径从样品表所在目录解析。同一个参考可供多个样品使用。所有输入必须在计算节点上可访问，并在运行及重试期间保持不变。

集群上只需准备代码、填好的样品表、选定的 FASTQ 和对应的 FASTA。个人样品表和分析结果不要提交进软件仓库。
